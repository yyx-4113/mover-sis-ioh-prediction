I, the author, verify the following:

1. **Provenance.** Every quantitative result reported in the manuscript is generated by the
   analysis pipeline in this repository from result files traceable through
   `results/s4_audit_trail.csv`, which records, for each reported number, its producing artefact
   and the exact command that reproduces it.

2. **Reproducibility.** The pipeline (`scripts/run_all.py` → s1 → s2 → s3 → s4) regenerates all

   are stated as structural limitations. The model is internally validated only; no external
   validation is claimed.

   statement accurately describes what is and is not in the public repository.
